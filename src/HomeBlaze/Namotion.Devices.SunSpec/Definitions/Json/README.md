# SunSpec Model Definitions

The `model_*.json` files are the SunSpec Alliance model definitions from [sunspec/models](https://github.com/sunspec/models/tree/90b4a331dcca1d6eac69c1bead952fddcc5852e0/json), commit `90b4a331dcca1d6eac69c1bead952fddcc5852e0` (2026-08-20), licensed under the Apache License 2.0 (see `LICENSE`). They are unmodified.

To update: copy the files of a newer commit, update the commit here, regenerate the model classes with `dotnet run --project src/HomeBlaze/Namotion.Devices.SunSpec.Generator -- src/HomeBlaze/Namotion.Devices.SunSpec/Models/Generated` and review the diff.
