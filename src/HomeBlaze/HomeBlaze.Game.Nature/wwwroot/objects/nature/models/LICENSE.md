# Tree models

These models are from the "low poly nature pack" by flo-bit (https://github.com/flo-bit/low-poly-asset-packs, also at https://flo-bit.itch.io/low-poly-nature-pack), released under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/) as stated by the repository README ("All packs are licensed under CC0") and the pack README. They were taken unchanged from `nature-pack/glb/` at commit 61bbdb032e079c7276a6558cbedc3ef1ea8b1575. Each file is self-contained: vertex-colored materials, no textures, no animations, origin at the trunk base.
